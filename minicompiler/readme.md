# 编译原理 2025 大作业实现指南（minicompiler）

本文档基于《编译原理2025大作业.docx》的要求，汇总评分点并给出满分实现路线，便于在 `minicompiler` 目录中快速落地。记得在最终提交的 `readme` 文档开头标明参考代码链接，并突出你对参考实现的改动，避免被判定为抄袭。

## 评分点与必备特性

- 语言特性：仅需 `int`（可加分扩展到实型），支持注释、声明、赋值、`while/for`、`if`、输入输出。
- 运算：算术（`+ - * / % ^`）、关系（`== > < >= <= !=`）、逻辑（`&& || !`）。
- 功能与分值：词法分析 20 分；语法分析/语法树 30 分；中间代码（四元式等）10 分；类型检查 10 分；优化 10 分；运行指令与结果截图 20 分；附加：错误分析 5 分、汇编生成 5 分。

## 推荐目录结构

```
minicompiler/
  src/
    scanner.l          # 词法：flex
    parser.y           # 语法：bison，生成 AST
    ast.hpp/.cpp       # 抽象语法树节点 & 访问器
    ir.hpp/.cpp        # 四元式、中间代码生成
    semantic.hpp/.cpp  # 符号表、类型检查
    optimize.hpp/.cpp  # 常量折叠、死代码消除等
    codegen.hpp/.cpp   # 可选：汇编/目标代码
  include/             # 公共头文件
  tests/               # 用例（含截图输入）
  Makefile             # `flex`/`bison`/`g++` 一键编译
```

## 实现路线（对照满分）

1. **词法分析（20 分）**：
   - `scanner.l` 中定义关键字、标识符、整型常量、运算符、分隔符与注释规则（支持 `//` 与 `/* */`）。
   - 为行号/列号维护全局状态，便于错误定位。

2. **语法分析与语法树（30 分）**：
   - `parser.y` 写 LL(1)/LR 兼容的 C 子集文法，产生 AST 节点（如 `BinaryExpr`, `IfStmt`, `ForStmt`, `WhileStmt`, `DeclStmt`）。
   - 在规约动作里构建 AST，结尾输出 DOT/JSON 供截图展示。

3. **中间代码（10 分）**：
   - 在 AST 访问器中生成四元式 `(op, arg1, arg2, result)`；为控制流语句生成标签与跳转。
   - 支持输入输出的内置运算符（如 `READ`, `WRITE`）。

4. **类型检查（10 分）**：
   - 维护符号表（作用域栈）与类型系统（`int` 基础，可选扩展到 `double`）。
   - 对赋值、算术/逻辑/关系运算做类型兼容检查，并在错误时打印行列提示。

5. **代码优化（10 分）**：
   - 四元式层面的常量折叠、代数化简、死代码消除（DCE）。
   - 循环/条件的跳转优化（消除空跳转、合并连续标签）。

6. **附加功能**：
   - **错误分析（+5）**：自定义错误恢复（如同步记号）与人性化提示，输出错误统计。
   - **汇编生成（+5）**：根据四元式选择简单目标（如 RISC-V/MIPS/x86-64），使用模板方式发射指令，保证能运行基本算术/条件/循环。

7. **文档与截图（20 分）**：
   - 在 `readme`/报告中罗列编译命令（`make`, `./minic < test.c` 等）与对应输出截图（词法表、语法树、四元式、类型检查日志、优化前后对比、可选汇编/执行结果）。

## 运行与测试建议

- 开发命令：
  - `flex -o scanner.cpp scanner.l`
  - `bison -d -o parser.cpp parser.y`
  - `g++ -std=c++17 -Wall -Wextra -o minic parser.cpp scanner.cpp *.cpp`
- 最少准备两类用例：
  1. 覆盖所有语句类型的综合例子（含 `for/while/if`）。
  2. 专门的错误/边界用例（非法字符、未声明变量、类型不匹配）。
